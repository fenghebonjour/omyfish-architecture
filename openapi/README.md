# API contracts

OpenAPI 3 specs generated by springdoc from the running services (`/v3/api-docs`). They aren't hand-written, so they match the code.

| Spec | Service | Covers |
|---|---|---|
| [`identity.json`](identity.json) | identity-service | Registration, login, refresh and logout, password change, API keys, subscription checkout and status |
| [`species.json`](species.json) | species-service | Species catalog, photo identification, Bite Score forecasts, Quebec regulations (zone limits, consumption advisories, Q&A) |
| [`observation.json`](observation.json) | observation-service | Catch log CRUD and the public GeoJSON feed |
| [`notification.json`](notification.json) | notification-service | The per-user notification inbox |
| [`shop.json`](shop.json) | shop-service | Catalog, guest and signed-in carts, checkout, orders, returns |

All routes are served through the API gateway under `/api/v1`. Admin routes and payment-provider webhooks are left out of the published copies.

To browse one, paste it into <https://editor.swagger.io>.
